# Response Synthesizer Node (`src/core/agent/nodes/synthesizer.py`)

This node drafts the final natural language response.

- **What it does**: Translates raw mathematical outputs and forecast tables into a natural language summary and configures dashboard charts.
- **Why it exists**: Converts raw numbers and arrays into a clear, conversational answer for the user.
- **Interview explanation**: "The synthesizer takes our raw calculation tables and drafts a clear, conversational explanation, configuring interactive charts for the UI dashboard."
- **Concepts used**: Response generation, context integration.
