# Custom React Hooks (`frontend/src/hooks/`)

This directory houses reusable custom hooks.

- **What it does**: Wraps state, effects, and API calls into custom React hooks (e.g. `useDashboard`, `usePredictions`, `useWorkspace`).
- **Why it exists**: Encourages reuse and simplifies components by isolating state logic.
- **Interview explanation**: "This folder contains our custom React hooks. By wrapping state and fetch tasks into hooks like `useDashboard`, we keep our UI components clean and focused purely on rendering."
- **Concepts used**: Custom hooks, state hooks.
