# Stylesheets & CSS Layouts (`frontend/src/index.css` & `App.css`)

These files configure styles and design properties.

- **What it does**: Standardizes margins, sets up custom CSS animations, and overrides browser default styles.
- **Why it exists**: Customizes global styles to match our dark-mode dashboard theme.
- **Interview explanation**: "These stylesheets declare our CSS custom variables (such as colors, margins, and gradients) and configure animations for things like the thinking indicators."
- **Concepts used**: Custom CSS variables, transitions.
