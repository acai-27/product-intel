# Design System UI Atoms (`frontend/src/components/ui/`)

This directory houses our base component library atoms.

- **What it does**: Implements basic elements (buttons, cards, badges, loading skeletons, table layouts) matching our theme.
- **Why it exists**: Enforces a consistent look and feel across the entire app by using standard base components.
- **Important files**:
  - `Button.tsx`: Customizable button component.
  - `Card.tsx`: Standard container with border properties.
  - `Badge.tsx`: Pill-shaped label for status tags.
  - `Skeleton.tsx`: Pulsing loading state layouts.
  - `Table.tsx`: Styled grid components.
- **Interview explanation**: "This folder contains our base components. By isolating buttons, containers, and table layouts, we can build custom views quickly while keeping the UI consistent."
- **Concepts used**: Base components, styling tokens.
