# Utility Helpers & Formatters (`frontend/src/utils/`)

This directory houses formatters and markdown rendering helpers.

- **What it does**: Formats numbers and currency strings, and configures custom markdown renderers for the chat interface.
- **Why it exists**: Consolidates layout formatters and parser logic.
- **Important files**:
  - `formatters.ts`: Formats currency and percentages.
  - `chartTheme.ts`: Defines color themes for Recharts.
  - `mdRenderer.ts`: Renders markdown text into JSX.
- **Interview explanation**: "This folder contains formatting and rendering utilities. It handles decimal precision, standardizes currency formatters, and sets up chart color themes."
- **Concepts used**: Utility helpers.
