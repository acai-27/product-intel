# TypeScript Declarations (`frontend/src/types/` & `index.ts`)

This directory houses our global TypeScript interface contracts.

- **What it does**: Declares interfaces matching backend payloads (e.g. `ForecastData`, `AnomalyRecord`, `DriverDetail`).
- **Why it exists**: Enforces static type safety, ensuring our frontend models match backend schemas exactly.
- **Interview explanation**: "This file declares our global type definitions, ensuring consistent types across components, services, and hooks."
- **Concepts used**: Interface declarations, static types.
