# Layout Configurations (`frontend/src/layouts/` & `MainLayout.tsx`)

This directory manages page layouts and wrappers.

- **What it does**: Wraps page components in a layout container that includes side navigation, title headers, and theme controllers.
- **Why it exists**: Enforces a consistent header and sidebar across all pages.
- **Interview explanation**: "This layout component wraps all views, ensuring that navigation rails, header sections, and theme controls remain consistent across pages."
- **Concepts used**: Layout wrapping.
