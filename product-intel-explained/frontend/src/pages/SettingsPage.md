# Settings Page View (`frontend/src/pages/SettingsPage.tsx`)

This page component manages configuration settings.

- **What it does**: Allows users to configure API endpoints, select LLM settings, and toggle mockup/sandbox options.
- **Why it exists**: Provides an interface for developers and admins to customize the application environment.
- **Interview explanation**: "This page manages system settings. It lets users configure API base URLs, toggle LLM parameters, and save settings to local storage."
- **Concepts used**: Application settings, form state.
