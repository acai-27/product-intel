# Global Styles & Component Classes (`frontend/src/design-system/`)

This directory houses custom styling rules and UI CSS classes.

- **What it does**: Configures dark-mode styling tokens and overrides UI elements using standard CSS sheets (`components.css`).
- **Why it exists**: Consolidates all styling overrides and variables in a single location.
- **Interview explanation**: "This module houses our global styling rules and dark-mode tokens, ensuring consistent styling across custom elements."
- **Concepts used**: CSS variables, styling overrides.
