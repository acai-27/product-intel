# TypeScript Configuration (`frontend/tsconfig.json`)

This file configures type-checking rules for the React client.

- **What it does**: Enforces type checks, compiles JSX, and resolves paths for TypeScript compilation.
- **Why it exists**: Catches typing bugs in the editor and compiler before they reach runtime.
- **Interview explanation**: "This configuration file sets up TypeScript rules for the frontend, ensuring strict type-safety across components and API hooks."
- **Concepts used**: TypeScript compilation, type checks.
