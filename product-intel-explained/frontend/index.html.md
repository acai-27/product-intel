# Entry Point Page (`frontend/index.html`)

This file serves as the main HTML page for our single-page application.

- **What it does**: Mounts the React application to the DOM and loads fonts and stylesheets.
- **Why it exists**: Serves as the index page, linking stylesheets and booting the React script.
- **Interview explanation**: "This is the single-page application's index shell. It loads Google Fonts and mounts our React script to the root element."
- **Concepts used**: DOM mounting.
