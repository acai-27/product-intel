# Frontend Configuration Overview (`frontend/package.json`)

This file manages client-side dependencies and build tasks.

- **What it does**: Declares React, Vite, Tailwind CSS, Recharts, and TypeScript dependencies.
- **Why it exists**: Configures scripts to run, lint, compile, and bundle our frontend assets.
- **Interview explanation**: "This is our NPM configuration file. It pins our UI dependencies—like React, Tailwind, and Recharts—and configures build tasks for our production assets."
- **Concepts used**: Package management, build pipelines.
